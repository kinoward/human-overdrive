# 项目文档同步

遵守[全局约束](../../../AGENTS.md)，按[文档地图](../../../docs/MAP.md)确定事实归属，复用本任务已经读取的上下文。

## 执行

1. 查看本次差异，判断需求、架构、运行方式、任务状态或文档引用是否变化；没有变化就结束，不产生形式性文档更新。
2. 按[维护归属表](../../../docs/规范/开发流程.md#按改动维护)只更新相关权威文档。项目事实归对应主题页，不写回全局约束或通用技能；未知项标为待确定，区分预期行为与实际实现，其他文档通过链接引用。
3. 新增、移动或删除文档时，按文档地图中的当前主题目录归档，同步调整目录树与受影响引用；确有新主题时才增加分类。已解决的问题从当前计划移除，历史过程留在提交正文。

文档更新后直接交由[项目提交技能](../project-commit/SKILL.md)提交，验证范围遵守全局约束，不另设检查流程。
