# 项目文档同步

遵守[全局约束](../../../AGENTS.md)，按[文档地图](../../../docs/MAP.md)确定事实归属。复用本任务已经读取的上下文与检查结果。

## 执行

1. 查看本次差异，判断需求、架构、运行方式、任务状态或文档引用是否变化；没有变化就结束，不产生形式性文档更新。
2. 按[维护归属表](../../../docs/开发流程.md#按改动维护)只更新相关权威文档。未知项明确标为待确定，区分预期行为与实际实现；其他文档通过链接引用，不复制事实。
3. 新增、移动或删除文档时修正地图和受影响引用；已解决的问题从当前计划移除，历史过程留在提交正文。
4. 文档或引用改变后执行下方检查；本轮相同内容已通过时不重复运行。脚本只检查链接，仍需核对文字是否符合真实实现。

## 文档检查

在仓库根目录运行，仅使用 Python 3 标准库，不联网、不安装依赖、不生成报告文件：

```sh
python3 .agents/skills/project-doc-sync/scripts/check_links.py
```

失败时修正具体引用，再检查受影响内容。本技能不启动游戏构建、不新增测试，也不执行提交；提交由[项目提交技能](../project-commit/SKILL.md)负责。
