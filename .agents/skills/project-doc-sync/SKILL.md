# 项目文档同步

遵守[全局约束](../../../AGENTS.md)，按[文档地图](../../../docs/MAP.md)确定事实归属，复用本任务已经读取的上下文。

## 执行

1. 查看本次差异，判断需求、架构、运行方式、任务状态或文档引用是否变化；没有变化就结束，不产生形式性文档更新。
2. 按[维护归属表](../../../docs/开发流程.md#按改动维护)只更新相关权威文档。未知项明确标为待确定，区分预期行为与实际实现；其他文档通过链接引用，不复制事实。
3. 新增、移动或删除文档时修正地图和受影响引用；已解决的问题从当前计划移除，历史过程留在提交正文。

文档更新后直接交由[项目提交技能](../project-commit/SKILL.md)提交。本技能不执行格式化、lint、Markdown、链接、技能结构、空白等校验或任何文档测试，不启动游戏构建，不增加校验脚本或依赖。
