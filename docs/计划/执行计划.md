## 后续顺序

1. 完成编辑器安装和许可激活，打开 `unity/Assets/Scenes/Demo.unity`，先确认成熟汽车、摩托和车损预制体能运行；仅按实际编译错误做必要版本兼容修订。
2. 复用成熟模型和现成材质／环境光，先取得一辆车与一段道路场景的实际美术基准，不以占位方块或贴图文件存在代替画面验收。
3. 复用现有北京道路数据接入 Unity；补齐可驾驶边界与主辅路隔离带碰撞，只允许从真实连接口切换道路。
4. 将本项目独有的追捕、累计里程和结算规则接到框架已有车控、损坏与 AI 入口；玩家车辆关闭示例自动扶正与调试复位，保留翻车失败。
5. 接入城市／选车／排行／评分界面，再按最终交付入口完成核心流程的手动验证。

## 保留的网页参考

此前 Three.js／Rapier 网页原型已有真实北四环水平路网、两种示意车辆、交通与警追，以及关卡、选车、指南、HUD、暂停、结算与本机双榜。

此前 `npm run build` 通过；Chrome 手动确认过城市与选车、两车型加速、汽车转向、近失得分、警告升级至三级与相应警车／直升机、暂停继续、摩托碰撞翻车、结算分项、双榜过滤和刷新保存。这些结果仅属于旧版。

旧版仍存在路外可行驶、隔离带不完整、程序化模型简陋及无完整视觉车损等差距；未人工跑完完整 5 公里、最高追捕 10 星和全部主辅路连接。当前不继续扩展该技术底层，保留代码和数据用于迁移参考。
