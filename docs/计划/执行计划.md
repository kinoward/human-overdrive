# 执行计划

[返回文档地图](../MAP.md)

## 当前主线

沿用 Three.js + Rapier + TypeScript + Vite。本轮按用户确认扩展完整四环主路与辅路，保持真实长度和连接关系，场景采用容易落地的简化写实方向；建筑和植被适度简化，优先道路、边界与驾驶体验。

## 已完成

- 已按欧卡2的道路层次与街区节奏改版：增加克制轮迹、直行箭头、路缘、反光柱、弯道诱导牌、局部隔音屏和桥栏细节；地面辅路补充中文商铺、办公、仓储与铺装，住宅、树木和花坛避让街铺占地，天空加入连续云层与远景薄雾。复用已生成住宅和树木，未新增在线模型生成。`npm run build -- --outDir artifacts/human-overdrive-ets2-dist` 通过，在独立成品地址 `http://127.0.0.1:5198/` 人工确认选城、出发、短程加速至约 117 km/h、里程累计、沿线街景、暂停和重新开始；该页错误与警告记录为空。全线匝道、全部隔音屏路段及最高警力表现尚未逐段验证。
- 已修正固定物理步进与显示混用：车辆、轮胎、车流按前后状态插值，镜头读取统一显示姿态；稳定阴影，连接道路带端点并启用内部边修正，处理路面与标线深度冲突。
- 已通过 Chrome 使用主办方 Tripo 生成并接入 SUV、摩托与骑手、住宅、行道树四套 GLB，共约 3.5 MB；两车型保留独立轮轴，交通和警车共享 SUV，沿线建筑与树木实例化复用，树木有远近细节。车型展示为通用生成车型，避免冒充指定品牌型号。
- 最新构建通过；前台短程起步窗口采样约 33–60 FPS，仍有负载波动，已确认生成车辆、道路与场景正确加载，SUV 四轮、摩托双轮接地与暂停正常。性能读数是局部采样，最高警力、完整通关及全线连接仍未重新验证。

- 普通 NPC 车流已加入统一快照决策、跨分段变道预约、持续扫掠和安全回撤，补齐目标道路后车及高速横穿预测；窄双向匝道按方向预约，入口前等候、出口检查、车尾清空后轮换，并过滤无合法出口方向。已补充 SUMO 连续变道、合流与窄路以及 Rapier 运动学边界的一手资料；本轮 `npm run build` 通过，Chrome 人工观察起跑、主路车流、加速、停车和暂停，错误与警告记录为空。全部窄匝道轮换、密集变道与极端切入尚未逐项人工验收。
- 已完成[警车与直升机追逐、碰撞重设计](../调研/警方追逐与碰撞.md)，核对道路约束、前视跟踪、多车分工、Rapier 接触事件及空中避障资料，记录近场跨隔离直追、上下层误围堵和直升机缺少实体碰撞等缺口。本次只交付调研文档，未改动或运行追捕实现。
- 已完成[汽车与摩托控制体系调研](../调研/车辆控制体系.md)，将操控目标明确为《狂野飙车》《暴力摩托》式抽象街机方向，建议保留 Rapier 碰撞世界并共享驾驶规则。候选引擎仅核对官方资料与源码，未安装或做性能比较。
- 已接入两车型共享的街机镜头：加速后拉与视野扩张、高速低机位、转向侧倾，摩托响应更快；后视减弱姿态，开局清理历史。该改动 `npm run build` 通过；在 `http://127.0.0.1:4173/` Chrome 人工观察汽车起步、加速、短促转向、后视、暂停和重开，摩托加速至约 122 km/h 时视野扩张可见，随后碰撞摔车正常进入结算；该试玩页错误与警告记录为空。本轮未验证完整通关或最高追捕。
- 已从 Chrome 的 Overpass Turbo 取得完整四环数据，补齐以桥名标注的主路，筛除主路外接支线并保留原始数据。当前为 590 条路径，双向主路形成约 65.294／65.173 公里闭环，另有 85 条辅路与 423 条匝道。
- 已接入真实米制道路、简化桥隧高差、实际路面碰撞、外缘护栏与实体边界；依据真实共同节点保留同层连接口，外部路网断头末端封闭。地图总长度与 5000 米单局目标独立。
- 已接入 Poly Haven 沥青、混凝土、HDR 与中文字体，增加立体建筑窗框、阳台、屋顶设施、分叉树干、多簇树冠和花坛。按空间块组织渲染与附近护栏碰撞，警方导航取消邻近平行道路直接连边，交通适配道路高差与连续连接。
- 已在主办方 V2FUN 生成写实与风格化两张参考图并保存到仓库。用户更喜欢偏写实效果，当前采用简化写实方向；参考图不是已导入的模型或最终画面承诺。
- 本轮 `npm run build` 通过；在最终 `http://127.0.0.1:4173/` Chrome 入口人工确认汽车、摩托起跑与加速、轮胎接地、有效里程、汽车护栏阻挡、暂停及返回选车，观察到四级追捕与相应警力。该入口的浏览器错误与警告记录为空。
- 已使用内置图片生成制作并接入 7 张统一写实竞速素材：雨后 SUV 主菜单背景、摩托选车图及五城地图，WebP 图像共约 4.14 MB。五城以真实地图为依据，主要四环、水系、海岸和主路方向经过对照核查；仅生成美术与来源元数据随包分发，原始地图参考在本机归档。菜单保持简洁流程，视觉统一为冷黑、钢蓝和荧光黄，并同步选车、HUD、暂停与结算。完整工作区初次构建通过；为避开并行场景任务尚未产出的三维资源，再以已提交版本加本任务文件独立构建并通过，在 `http://127.0.0.1:4177/` Chrome 桌面入口确认主图、五张地图加载、城市切换、预告禁用、信息标签、车型切换、摩托起跑与暂停。未进行手机版本测试，未重验完整通关与最高追捕。

## 当前待处理

- 普通车流仍采用运动学车体，未接入完整物理车体扫掠或通用倒车解堵；玩家蓄意封路、突发切入和既有异常重叠不能保证自动消解，需继续逐段人工体验窄匝道与密集合流。
- 警方追逐与碰撞新方案尚未实现：优先修正接触强度和围堵误判，再接入持续道路约束、多车分工及直升机避障遮挡；具体边界与建议顺序见对应调研，不能将设计完成写成玩法已验证。
- 共享街机推进、转向和抓地仍为调研建议，当前继续使用已有射线车物理；摩托独立视觉压弯尚未实现。后续按已确认体验方向集中调校，具体边界见车辆控制调研。
- 尚未逐段人工驾驶完整四环、全部主辅路连接与立交；数据闭环不等于这些路径已经全部试玩通过。
- 尚未人工跑完完整 5 公里、最高 10 警车与 3 直升机下的 10 星通关、围堵失败；这些路径不能写成已验证通过。
- 桥隧高程与道路宽度来自标签和简化推定，缺少实测高程；需优先体验上下层交叉、匝道坡脚、护栏开口与断头封闭位置，修正局部可玩性问题。
- 车辆、交通、警车、住宅和行道树已使用生成 GLB，直升机仍是程序化外观，完整视觉车损尚未实现；局部细节和场景密度仍需按参考与实际设备继续调整。
- 主包包含物理 WebAssembly，源道路、美术与字体另随公开目录分发；已有局部帧率采样且出现低帧窗口，首次加载、内存与最高追捕的稳定表现仍未完整测量，不能据此宣称稳定 60 FPS。
