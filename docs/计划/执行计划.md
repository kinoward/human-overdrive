# 执行计划

[返回文档地图](../MAP.md)

## 当前主线

沿用 Three.js + Rapier + TypeScript + Vite。本轮按用户确认扩展完整四环主路与辅路，保持真实长度和连接关系，场景采用容易落地的简化写实方向；建筑和植被适度简化，优先道路、边界与驾驶体验。

## 已完成

- 普通 NPC 车流已重做为有向车道行进、平顺跟车、安全变道、同层预测制动和真实连接汇入，加入断头停车、空位出生及远距回收，刹车灯与转向灯反馈驾驶意图。最新 `npm run build` 通过；在最终 Chrome 预览入口人工观察主路车流和停车玩家附近的车辆通过，浏览器错误与警告记录为空。跨全部匝道、密集变道与极端切入尚未逐项人工验收。
- 已完成[警车与直升机追逐、碰撞重设计](../调研/警方追逐与碰撞.md)，核对道路约束、前视跟踪、多车分工、Rapier 接触事件及空中避障资料，记录近场跨隔离直追、上下层误围堵和直升机缺少实体碰撞等缺口。本次只交付调研文档，未改动或运行追捕实现。
- 已完成[汽车与摩托控制体系调研](../调研/车辆控制体系.md)，将操控目标明确为《狂野飙车》《暴力摩托》式抽象街机方向，建议保留 Rapier 碰撞世界并共享驾驶规则。候选引擎仅核对官方资料与源码，未安装或做性能比较。
- 已接入两车型共享的街机镜头：加速后拉与视野扩张、高速低机位、转向侧倾，摩托响应更快；后视减弱姿态，开局清理历史。该改动 `npm run build` 通过；在 `http://127.0.0.1:4173/` Chrome 人工观察汽车起步、加速、短促转向、后视、暂停和重开，摩托加速至约 122 km/h 时视野扩张可见，随后碰撞摔车正常进入结算；该试玩页错误与警告记录为空。本轮未验证完整通关或最高追捕。
- 已从 Chrome 的 Overpass Turbo 取得完整四环数据，补齐以桥名标注的主路，筛除主路外接支线并保留原始数据。当前为 590 条路径，双向主路形成约 65.294／65.173 公里闭环，另有 85 条辅路与 423 条匝道。
- 已接入真实米制道路、简化桥隧高差、实际路面碰撞、外缘护栏与实体边界；依据真实共同节点保留同层连接口，外部路网断头末端封闭。地图总长度与 5000 米单局目标独立。
- 已接入 Poly Haven 沥青、混凝土、HDR 与中文字体，增加立体建筑窗框、阳台、屋顶设施、分叉树干、多簇树冠和花坛。按空间块组织渲染与附近护栏碰撞，警方导航取消邻近平行道路直接连边，交通适配道路高差与连续连接。
- 已在主办方 V2FUN 生成写实与风格化两张参考图并保存到仓库。用户更喜欢偏写实效果，当前采用简化写实方向；参考图不是已导入的模型或最终画面承诺。
- 本轮 `npm run build` 通过；在最终 `http://127.0.0.1:4173/` Chrome 入口人工确认汽车、摩托起跑与加速、轮胎接地、有效里程、汽车护栏阻挡、暂停及返回选车，观察到四级追捕与相应警力。该入口的浏览器错误与警告记录为空。
- 已参考 Mini Motorways 重做首页、城市轮播与选车准备页，并统一排行榜、指南、比赛信息、暂停和结算样式。五座城市有独立原创插画，预告可浏览且禁止出发，关卡页展示北京本机最快逃脱；支持方向键浏览、明确确认选车与暂停焦点管理。`npm run build` 通过，已在最终 `http://127.0.0.1:4173/` Chrome 桌面入口人工确认连续方向键切换、预告禁用、北京选车、汽车出发、驾驶信息更新、暂停继续和返回首页；该入口的错误与警告记录为空。后续按用户要求只验收桌面版本，完整通关和结算重开流程未在本次改版重新试玩。

## 当前待处理

- 普通车流仍采用运动学车体，突发切入不能保证无碰撞；窄双向单车道匝道尚无完整交替路权，极端对向相遇可能互相停车，需结合实际试玩继续调整。
- 警方追逐与碰撞新方案尚未实现：优先修正接触强度和围堵误判，再接入持续道路约束、多车分工及直升机避障遮挡；具体边界与建议顺序见对应调研，不能将设计完成写成玩法已验证。
- 共享街机推进、转向和抓地仍为调研建议，当前继续使用已有射线车物理；摩托独立视觉压弯尚未实现。后续按已确认体验方向集中调校，具体边界见车辆控制调研。
- 尚未逐段人工驾驶完整四环、全部主辅路连接与立交；数据闭环不等于这些路径已经全部试玩通过。
- 尚未人工跑完完整 5 公里、最高 10 警车与 3 直升机下的 10 星通关、围堵失败；这些路径不能写成已验证通过。
- 桥隧高程与道路宽度来自标签和简化推定，缺少实测高程；需优先体验上下层交叉、匝道坡脚、护栏开口与断头封闭位置，修正局部可玩性问题。
- 车辆、交通、警车与直升机仍是程序化示意外观，完整视觉车损与外部 GLB／glTF 模型尚未接入。
- 界面改版后主包约 5.11 MB，源道路、美术与字体另随公开目录分发；尚未定量测量首次加载、内存、帧率和最高追捕时的表现。

## 后续顺序

1. 在最终入口优先体验代表性的主辅路连接、立交高差与实体边界，补齐完整 5 公里、围堵失败和最高评级的人工驾驶验证。
2. 根据实际 Chrome 体验调整场景密度、模型细节、纹理尺寸、可见范围与警力表现。
3. 继续采用简化写实方向，优先替换主角车辆和警车外观，再补充必要视觉车损与少量地点特征。
