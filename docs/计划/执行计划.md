## 当前状态

- 已完成：全局约束、Claude Code 专属约束、文档地图体系，以及文档同步与自动提交的项目技能。
- 已完成：相近游戏、引擎、比赛资产资源及 GIS 路线调研；通过问答确认北京精选主辅路、可重复累计里程、街机手感、摩托辅助、围堵失败、2–3 分钟单局与双榜，已记录到[产品规格](../产品/产品规格.md)。
- 当前状态：调研与首轮需求梳理已完成；游戏实现尚未开始，本轮未创建工程、领取资源或生成模型。
- 下一步：结合[调研建议](../调研/玩法与技术调研.md)收敛引擎、精选道路与可用车型，先做可驾驶、可碰撞翻覆的原型，再接入道路和追捕核心循环。

## 开发顺序

1. 确定最小玩法范围与演示标准，记录到[产品规格](../产品/产品规格.md)。
2. 选定技术并建立可运行入口，更新[架构地图](../架构/架构地图.md)和[实际命令](../架构/架构地图.md#实际命令)。
3. 按独立功能实现核心循环，完成必要验证并持续提交。
4. 仅在核心循环可演示后处理必要体验问题，预留最终试玩与交付时间。

这是执行顺序，不代表功能已完成，也不预设具体时间分配或额外功能。

## 阻塞与未解决问题

- 推荐 Godot 4.7.2 + GDScript，本机已安装；选型尚未正式落地。没有可运行工程，尚不能评估帧率与驾驶手感。
- 精选道路的实际 GIS 连通性、桥高与辅路入口尚未下载核实，需要在制作前确定区间并补齐缺失。
- BMW F 850 GS Adventure 与最新中国版 Model Y 是优先车型，用户允许为合适的开源模型更换车型；已找到车轮分件的低面数 Model 3、Hayabusa 摩托与 Kenney 交通资产候选，详见调研。尚未下载核实文件、选定最终车型与性能配置。
- 比赛资源页的 Tripo、Hyper3D 等权益已核实，但未领取、未确认账户实际额度。资产生成应与玩法实现并行，不能作为运行时依赖。
- 围堵/翻覆阈值、五级警力配比、直升机作用、最高追捕有效持续时间、具体评分公式和车型分榜仍是调研提案，不能当作已确认实现要求。
