# 执行计划

## 当前主线

沿用 Three.js + Rapier + TypeScript + Vite。本轮按用户确认扩展完整四环主路与辅路，保持真实长度和连接关系，场景采用容易落地的简化写实方向；建筑和植被适度简化，优先道路、边界与驾驶体验。

## 已完成

- 已落地汽车、摩托与动态警车共享的街机驾驶核心：统一推进、刹车、换向、速度相关转向与抓地，汽车保留轻微侧滑；高速转向加入横向加速度约束，并通过统一接口提供偏航上限。摩托视觉压弯最高约 33°，按固定步平滑并插值，与真实车体翻倒判定分离，碰撞恢复期间减弱辅助。
- 本次工作区构建及固定场景的独立构建通过。在 `http://127.0.0.1:5199/` 以已提交场景加本次车控和现有碰撞接入做人工驾驶，确认汽车加速、右转、刹停、倒车再前进；摩托左右压弯、双轮接地、松键刹停回正、暂停与重开，左压弯读回约 30°时真实车体仍接近直立。也观察到撞护栏后摔车结算；最终复验页面错误与警告记录为空。并行新增场景的完整加载、全部坡道及单轮／离地边界尚未逐项试玩，完整通关与最高警力不在本轮验证范围。
- 已保留 Rapier 接入碰撞分级、有限翻滚辅助、撞击镜头和合成音，以及生成 SUV／摩托的局部凹陷、玻璃面破损与真实部件脱落。碎片每车最多八片、七秒回收，不影响车辆碰撞；受支持 NPC 首次受撞才建立损伤状态，重定位与重开清理。复用 Randomation 的公开算法思路，已保留 MIT 来源声明。
- 本轮共享代码与按任务分离的提交版本均通过 TypeScript 编译和 Vite 构建。在使用已入库场景的独立副本 `http://127.0.0.1:5202/` 人工确认 SUV 约 133 km/h 加速、撞栏后凹陷/玻璃/部件变化、暂停与重开清零，以及摩托正常平衡、撞后翻倒且连续撞栏仅计一次；该页浏览器错误记录为空。随后在实际提交版本成品 `http://127.0.0.1:5203/` 复核启动、SUV 与警车碰撞后的车损、重开清零、摩托约 119 km/h 双轮接地与撞栏翻倒结算；此入口错误记录为空。隔离副本固定场景文件，实际提交版本不纳入并行尚未完成的新车型与追捕扩展；最高追捕、极端多车挤压和长时间碎片回收尚未完整人工验收。

- 警方新实现仍需逐项人工体验桥上桥下、隔栏近距、匝道切换、真正前后夹堵、10 警车与 3 直升机联合追逐、空中侧撞后的回正及完整通关；本轮未覆盖的场景不能写为验证通过。
- 街机驾驶核心仍需结合完整路网继续调校：重点人工体验坡顶、单侧压路缘、受撞离地、长时间高速变线及高警力碰撞恢复，不能把短程操控验证视作全线验收。
- 尚未逐段人工驾驶完整四环、全部主辅路连接与立交；数据闭环不等于这些路径已经全部试玩通过。
- 尚未人工跑完完整 5 公里、最高 10 警车与 3 直升机下的 10 星通关、围堵失败；这些路径不能写成已验证通过。

- 车辆、交通、警车、住宅和行道树已使用生成 GLB，直升机仍是程序化外观；生成 SUV／摩托已有轻量视觉车损，其他新增车型的分件车损与真实软体尚未接入，局部细节和场景密度继续调校。
- 主包包含物理 WebAssembly，源道路、美术与字体另随公开目录分发；已有局部帧率采样且出现低帧窗口，首次加载、内存与最高追捕的稳定表现仍未完整测量，不能据此宣称稳定 60 FPS。
