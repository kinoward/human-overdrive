## 地图维护

- README.md 提供项目介绍与阅读入口，AGENTS.md 维护通用开发约束，CLAUDE.md 维护仅在使用 Claude Code 时生效的约束，本页只做任务路由；项目事实归上表对应主题文档，不混入全局约束、通用流程或技能正文。
- 每类事实只在上表指定的文档维护，其他文档使用链接引用；地图不复制正文或进度。
- 新知识优先补入现有主题目录。只有独立主题确有需要时才拆出新文档或分类，并从本地图或所属主题页链接到它。
- 文档增加、移动或删除时同步更新目录树、入口和引用，不保留空目录、无用途的模板或无法到达的规范。
- 详细决策理由与验证结果记录在提交正文；正文档只保留后续开发需要的现状、规则和取舍。
