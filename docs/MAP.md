# 文档地图

本页只负责指路。先确定当前任务，再读取对应文档和相关代码；无需每次通读全部文档。

## 按任务查阅

| 当前任务 | 阅读入口 | 该文档负责的信息 |
| --- | --- | --- |
| 确认玩法、范围或完成标准 | [产品规格](产品规格.md) | 已确认需求、范围边界、验收目标 |
| 定位代码、选择技术或调整模块 | [架构地图](架构地图.md) | 实际技术栈、代码入口、模块职责与依赖 |
| 开始工作、交接或确认下一步 | [执行计划](执行计划.md) | 当前进度、下一步、阻塞与未解决问题 |
| 实现、验证、交付或维护文档 | [开发流程](开发流程.md) | 执行步骤、实际命令、最小验证与维护规则 |
| 核对开发代理必须遵守的规则 | [全局约束](../AGENTS.md) | 中文、模块化、注释、测试与提交等全局约束 |

## 地图维护

- README.md 只做项目阅读入口，AGENTS.md 维护全局约束，本页只做任务路由；详细事实归上表对应主题文档。
- 每类事实只在上表指定的文档维护，其他文档使用链接引用；地图不复制正文或进度。
- 新知识优先补入现有归属。只有独立主题确有需要时才拆出新文档，并从本地图或所属主题页链接到它。
- 文档增加、移动或删除时同步修正入口和引用，不保留空目录、无用途的模板或无法到达的规范。
- 详细决策理由与验证结果记录在提交正文；正文档只保留后续开发需要的现状、规则和取舍。
