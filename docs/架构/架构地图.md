## 当前实现

当前唯一开发与交付主线为根目录的 Three.js 0.187 + Rapier 0.21 + TypeScript 7 + Vite 8 网页工程。用户实测本机运行 Unity 负担过高，本次项目不再依赖 Unity 编辑器或 Unity 工程。

网页依赖、物理 WebAssembly 与道路数据从本地加载，使用固定 60 Hz 物理步长和 Three.js Timer。北京 GIS、汽车与摩托控制、普通交通、追捕、累计里程、结算及游戏外流程均在现有模块中实现；车辆和建筑仍是程序化示意外观，完整视觉车损尚未实现。当前道路带网格没有可供路面贴图使用的米制 UV，大地面仍允许车辆驶离道路；物理只在路外降速，规则层不累计路外里程，中央隔离带也尚未连续覆盖全部需要限制的路段。

`public/assets/art/` 已准备 Poly Haven CC0 沥青、混凝土贴图与 HDR 环境，以及开放中文字体和来源文件；当前代码尚未加载这些美术文件，也没有接入 GLB／glTF 模型，不能将源文件存在描述为画面已升级。

## 实际命令

### Three.js 主线

在仓库根目录使用 Node.js 与 npm：

| 目的 | 命令 | 结果 |
| --- | --- | --- |
| 安装依赖 | `npm install` | 安装 `package.json` 与锁文件声明的本地依赖 |
| 启动开发 | `npm run dev -- --port 5173` | 本机 `http://127.0.0.1:5173`；不指定端口时 Vite 默认 5173 |
| 编译与打包 | `npm run build` | 先执行 TypeScript 编译检查，再用 Vite 生成 `dist/` |
| 预览产物 | `npm run preview` | 本机 `http://127.0.0.1:4173`，需先生成 `dist/` |
| 更新道路 | `node scripts/fetch-road-data.mjs` | 联网查询 Overpass 并更新本地道路数据，常规启动无需执行 |

游戏通过本地 HTTP 服务运行，不以双击 HTML 的方式启动。生产交付为静态 `dist/`，依赖与资产随包提供；本机成绩按浏览器与站点地址隔离，开发地址和预览地址不会共享排行榜。

当前工程此前已通过 `npm run build` 并在 Chrome 启动，范围见[执行计划](../计划/执行计划.md)。包含物理 WebAssembly 的主包约 4.95 MB；接入模型、贴图和环境资源后，需要依据实际加载与运行表现调整资源规模，不能沿用旧构建结果推断最终包体或帧率。

## 复用与数据边界

用户提供的 [Three.js 创建场景教程](https://threejs.org/manual/pages/creating-a-scene.html)、[API 文档](https://threejs.org/docs/)和 [GitHub 源码](https://github.com/mrdoob/three.js)是官方技术资料入口，不是已安装的项目技能。车辆实现参考官方 Rapier 车辆示例的射线悬挂思路，Timer 与 WebGL 2 使用官方 API；游戏流程、城市路网、追捕与评分由本项目组织。

北四环 OSM 数据合并为 32 条路径并由当前网页场景使用。Poly Haven CC0 材质、环境光与开放中文字体已移动到 `public/assets/art/`，但尚未接入渲染流程；赞助平台生成资产也尚未导入。新增素材必须保留来源、作者、许可与修改说明。

玩法规则统一维护在[产品规格](../产品/产品规格.md)。
