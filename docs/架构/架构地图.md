## 当前实现

当前开发主线为 `unity/`，以 Unity `6000.3.12f1` 为目标编辑器，复用 Randomation Vehicle Physics 的固定提交 `192ba860c3c92a16363ffe87fb943dc282e62398`。完整上游场景、车辆预制体、物理输入设置和 `.meta` 已导入。上游项目来自 Unity 2019.4，当前仅设定目标版本，尚未通过 Unity 6 实际编译与运行。

保留 Built-in 材质与完整样例，优先跑通现成框架，不提前进行渲染管线转换。汽车、摩托、车损、掉件、玻璃破裂与跟随 AI 复用框架；北京 GIS、持续警告、累计里程和本项目结算将在框架验证后接入，当前未完成这部分迁移。来源、版本和导入边界见 [Unity 来源记录](../../unity/UPSTREAM.md)。

根目录的 Three.js 0.187、Rapier 0.21、TypeScript 7 与 Vite 8 工程是此前可运行的网页参考版，其已有运行结果不代表 Unity 版已验证。网页依赖、物理 WebAssembly 与道路数据从本地加载，使用固定 60 Hz 物理步长和 Three.js Timer。

## 实际命令

### Unity 主线

Unity `6000.3.12f1` 已安装。使用编辑器打开仓库内 `unity/`，先加载 `Assets/Scenes/Demo.unity`。用户已同意官方安装协议并确认已有账号，但尚未激活编辑器许可；一次批处理启动在编译前返回 `No valid Unity Editor license found`，因此尚无已通过的 Unity 编译、运行或构建结果。

### 已保留的网页参考版

在仓库根目录使用 Node.js 与 npm：

| 目的 | 命令 | 结果 |
| --- | --- | --- |
| 安装依赖 | `npm install` | 安装 `package.json` 与锁文件声明的本地依赖 |
| 启动开发 | `npm run dev -- --port 5173` | 本机 `http://127.0.0.1:5173`；不指定端口时 Vite 默认 5173 |
| 编译与打包 | `npm run build` | 先执行 TypeScript 编译检查，再用 Vite 生成 `dist/` |
| 预览产物 | `npm run preview` | 本机 `http://127.0.0.1:4173`，需先生成 `dist/` |
| 更新道路 | `node scripts/fetch-road-data.mjs` | 联网查询 Overpass 并更新本地道路数据，常规启动无需执行 |

游戏通过本地 HTTP 服务运行，不以双击 HTML 的方式启动。生产交付为静态 `dist/`，依赖与资产随包提供；本机成绩按浏览器与站点地址隔离，开发地址和预览地址不会共享排行榜。

网页参考版此前已通过 `npm run build` 并在 Chrome 启动，范围见[执行计划](../计划/执行计划.md)。包含物理 WebAssembly 的主包约 4.95 MB；这些是旧版结果，不作为当前性能优化任务。

## 复用与数据边界

用户提供的 [Three.js 创建场景教程](https://threejs.org/manual/pages/creating-a-scene.html)、[API 文档](https://threejs.org/docs/)和 [GitHub 源码](https://github.com/mrdoob/three.js)是官方技术资料入口，不是已安装的项目技能。车辆实现参考官方 Rapier 车辆示例的射线悬挂思路，Timer 与 WebGL 2 使用官方 API；游戏流程、城市路网、追捕与评分由本项目组织。

北四环 OSM 数据合并为 32 条路径，仍保存在网页参考工程，尚未导入 Unity 游戏场景。Unity 已取得框架成熟模型与纹理、Poly Haven CC0 材质和环境光、Adobe 开放中文字体；尚未接入赞助平台生成资产。新素材的原始来源、作者、许可和字体固定版本保存在 Art/SOURCES.json 与资产来源页。

玩法规则统一维护在[产品规格](../产品/产品规格.md)。
