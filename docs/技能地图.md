## 保存与发现

- `.agents/skills/` 是项目技能的唯一正文来源，随仓库提交；Codex 从此目录发现技能。
- `.claude/skills/` 下的同名目录使用仓库内相对软链接指向对应技能，Claude Code 共用同一份正文；新增技能时同步建立入口，不复制第二份规则。
- [CLAUDE.md](../CLAUDE.md) 仍只保留全局约束引用；全局约束、技能入口和文档事实分别维护，不将技能正文塞入全局约束。
- 技能未出现在工具列表时，可通过本页直接读取真实 `SKILL.md` 执行；路径与资源均留在仓库内，不依赖用户级技能目录。

## 增加或调整技能

1. 确认操作确实会重复，先检查本页已有技能及当前可用技能；已有覆盖就直接复用，不为每个小操作单独创建技能。
2. 只有存在实际缺口时，再查找适合的社区技能。核对源码、许可证和固定版本，优先裁剪已有流程；没有合适来源时才独立编写。
3. 项目专属或经项目规则改造的技能只保存到仓库，不新增或修改全局技能。系统已有通用技能仍可按需使用；技能默认要求与本项目约束冲突时，调整本地技能，以用户当前要求和项目约束为准。
4. 正文只保留触发条件与必要步骤。稳定且重复的机械操作确有收益时才增加脚本，不引入完整测试、审批、发布或依赖安装流程；不在每次开发时重新联网搜索。
5. 更新本页入口与来源记录，检查技能结构、引用和新增脚本的实际运行结果。只有技能变化时才进行技能结构校验。
