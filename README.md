# 追逐最后的自由

本项目参加 VibeHacks #06，制作面向全球城市、以车技星级为核心的城市追逐游戏，目前仅实现北京可玩 Demo。最初希望引入类似 Google Earth 的实景三维城市作为赛道，受开发时间与技术要求限制暂未实现；当前采用真实路网改编与简化三维场景，愿景和交付范围见[产品规格](docs/产品/产品规格.md)。本次项目完全使用 Three.js + Rapier + TypeScript + Vite；优先复用许可明确的成熟模型、场景与美术资产，项目独有的路网逃跑、追捕和评分逻辑由本项目实现。

[在线游玩](https://kinoward.github.io/human-overdrive/) · [自动构建与发布记录](https://github.com/kinoward/human-overdrive/actions/workflows/deploy-pages.yml)

选择城市和座驾，在城市路网的主路、辅路与连接匝道间自由行驶；逆行与同路往返均累计，完成 20 公里即可逃脱，单局节奏约 10 分钟。开局有 3 辆警车，随比赛时间逐步增援至最多 10 辆仍能追捕的警车；损坏退出的车辆留在路上，翻车或被围堵到无法脱困会结束挑战。

## Three.js 主线

根目录网页工程已实现城市关卡、选车、驾驶指南、HUD、暂停、结算及本机双榜。北京使用离线 OSM 完整四环路网，并在长直路加入 12 段 S 弯与长缓弯；源主路单圈约 65.294／65.173 公里，游戏里程按改编后道路计算，单局目标为 20 公里。道路已接入实体护栏、桥隧层级简化高差与成熟路面材质，沿线采用简化三维建筑与植被；汽车和摩托采用 Rapier 射线悬挂与街机控制，普通交通、按时间增援的警车和直升机已接入。其他城市仅作预告。

当前车辆和建筑仍是程序化示意外观，完整视觉车损尚未实现。后续在保留可玩流程的基础上改善材质和光照，补齐道路边界，并按浏览器实际负担分批接入 GLB 模型与可重复场景模块；具体顺序见[执行计划](docs/计划/执行计划.md)。

本机开发入口为：

```sh
npm install
npm run dev -- --port 5173
```

在 Chrome 打开 `http://127.0.0.1:5173`。使用 WASD 或方向键驾驶、空格刹车、Esc 暂停或继续。比赛中的 C 键可向后观察。

```sh
npm run build
npm run preview
```

预览默认地址为 `http://127.0.0.1:4173`，构建产物位于 `dist/`。详细运行方式与模块入口见[架构地图](docs/架构/架构地图.md#实际命令)，实际验证进度见[执行计划](docs/计划/执行计划.md)。
