# 人类超频 · 北京逃亡

本项目参加 VibeHacks #06，在 6 小时开发预算内制作城市道路警追游戏 Demo。首版采用 Three.js、Rapier、TypeScript 与 Vite，在电脑浏览器中运行。

选择北京和座驾，在真实北四环水平路网重构的主路、辅路与匝道间自由行驶；逆行与同路往返均累计，完成 5 公里即可逃脱。违规后警告持续升级，翻车或被围堵到无法脱困会结束挑战。

城市关卡、选车、驾驶指南、暂停、结算及本机计时／车技双榜已接入原型。北京可玩，上海、重庆、东京和洛杉矶为预告。车辆与建筑使用程序化示意外观，性能为街机调校；尚未接入精细车型模型或 AI 生成资产。

## 运行

```sh
npm install
npm run dev -- --port 5173
```

在 Chrome 打开 `http://127.0.0.1:5173`。使用 WASD 或方向键驾驶、空格刹车、Esc 暂停或继续。比赛中的 C 键可向后观察。

```sh
npm run build
npm run preview
```

预览默认地址为 `http://127.0.0.1:4173`，构建产物位于 `dist/`。详细运行方式与模块入口见[架构地图](docs/架构/架构地图.md#实际命令)，实际验证进度见[执行计划](docs/计划/执行计划.md)。
