# 人类超频 · 北京逃亡

本项目参加 VibeHacks #06，在短开发窗口内制作城市道路警追游戏 Demo。当前主线采用 Unity，优先复用开源社区成熟框架、技术、模型、场景与美术资产；只有合适资源确实缺失的项目逻辑才自行实现。

选择北京和座驾，在真实北四环水平路网重构的主路、辅路与匝道间自由行驶；逆行与同路往返均累计，完成 5 公里即可逃脱。违规后警告持续升级，翻车或被围堵到无法脱困会结束挑战。

## Unity 主线

工程位于 `unity/`，以 Unity `6000.3.12f1` 为目标，采用 [Randomation Vehicle Physics](https://github.com/JustInvoke/Randomation-Vehicle-Physics) 的固定提交。完整 Demo、汽车、摩托、货车、公交、车辆损坏、掉件和玻璃破裂能力直接复用上游；代码采用 MIT，模型与纹理由原作者按 Public Domain 提供。声音与字体分别保留其许可。

已取得 CC0 的道路／混凝土贴图、HDR 环境与开放中文字体。先使用成熟预制体和示例场景确认车控、损坏与画面，再接入北京 GIS、警告、累计里程、关卡与排行榜。优先提高美术真实性和统一完成度，不以性能优化为当前重点。

入口为 `unity/Assets/Scenes/Demo.unity`。当前为框架和资源导入阶段，Unity 6 的实际导入、编译与运行尚未通过；编辑器安装与许可激活状态见[执行计划](docs/计划/执行计划.md)。固定来源、许可和边界见 [Unity 来源记录](unity/UPSTREAM.md)。

## 已保留的网页参考版

根目录的 Three.js／Rapier 工程保留为已有玩法和交互参考。它已有城市关卡、选车、驾驶指南、暂停、结算及本机双榜，北京可玩，其他城市为预告；车辆和建筑为程序化示意外观。下面命令运行的是旧网页原型，不是 Unity 版。

```sh
npm install
npm run dev -- --port 5173
```

在 Chrome 打开 `http://127.0.0.1:5173`。使用 WASD 或方向键驾驶、空格刹车、Esc 暂停或继续。比赛中的 C 键可向后观察。

```sh
npm run build
npm run preview
```

预览默认地址为 `http://127.0.0.1:4173`，构建产物位于 `dist/`。详细运行方式与模块入口见[架构地图](docs/架构/架构地图.md#实际命令)，实际验证进度见[执行计划](docs/计划/执行计划.md)。
